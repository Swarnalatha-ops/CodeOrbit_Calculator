# Simple Calculator

A beginner-friendly command-line calculator developed using Python as part of the CodeOrbit Tech Python Programming Internship.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Takes user input
* Handles invalid input
* Handles division by zero
* Uses try/except for error handling

## Technologies Used

* Python 3

## Setup Instructions

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in Command Prompt or Terminal.
4. Run the following command:

```bash
python calculator.py
```

## Example

```text
========================================
       SIMPLE CALCULATOR
========================================
Enter the first number: 20
Enter the second number: 5

Choose an operation:
+  Addition
-  Subtraction
*  Multiplication
/  Division

Enter operator (+, -, *, /): +

----------------------------------------
Result: 20.0 + 5.0 = 25.0
----------------------------------------
```

## Error Handling

The program handles invalid input and division by zero using Python's try/except mechanism.

Example:

```text
Error: Cannot divide by zero.
```
